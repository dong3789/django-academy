# 레슨 작성 가이드 (STYLE v3)

독자: Node.js 개발자, **휴대폰으로 읽음**.
목표: 전체 과정은 면접·실무 수준, 하지만 **하루치는 10~15분에 소화**.
프로젝트: 전 과정이 **Goals 대시보드**(취미 목표·진행률 추적)를 키워 나간다.

## 0. 분량 규칙 (가장 중요)

- 하루 = **핵심 개념 3개 내외**.
- 마크다운 **250~400줄** (접힌 "더 깊이" 포함 최대 ~450줄).
- 넘치면 내용을 버리지 말고 → `더 깊이 (면접용)` 접기 섹션으로 옮긴다.
- 그래도 넘치면 → 다음 날로 쪼갠다.
- **1–3주차 본문**은 "오늘은 앱에 이 기능을 붙인다"가 중심.
  CS·내부 구현은 접기 또는 Week 11–12.

## 1. 레슨 뼈대

```text
# Day N · 제목
> 읽는 시간: 약 12분

## 복습 3문제          ← 이전 날들에서 (Day 1은 워밍업)
## 오늘 만들 것         ← Goals 앱에 붙일 기능 1줄
## 오늘 배울 것         ← 한 줄 3개

## 1. 개념 A            ← 아래 "개념 흐름"
## 2. 개념 B
## 3. 개념 C

## 연습문제 (최대 3개)
## 면접 질문 (1~2개)    ← 접기 가능
## 오늘 정리 (3줄)
## 다음에 이어갈 것     ← Goals 앱 다음 스텝 한 줄
```

## 2. 개념 하나 = 예측 → 비교 → 설명

1. **결과를 맞혀 보세요** (필수)
   - 짧은 코드 또는 "이 버튼을 누르면?" 질문.
   - 정답은 `<details><summary>정답</summary>…</details>`에.
   - 설명 **전에** 둔다. 틀린 뒤가 학습이다.
2. **JS ↔ Python 나란히** — `**JS (Node)**` / `**Python**` 라벨.
   - 각 블록 8줄 이하, 줄당 45자 이하.
3. **일상 비유** — 1~3문장.
4. **그림** — ` ```mermaid ` 또는 GIF (`assets/gif/…`).
5. **실행 가능한 순수 Python** — ` ```python-run ` (아래 §5).
   Django/ORM/서버 코드는 ` ```python ` 또는 ` ```bash `로
   **로컬에서 실행**하라고 안내만 한다 (Pyodide에 Django 없음).
6. **💡 한 줄 요약** — `> 💡 ...`

### 2-1. 움직이는 그림(GIF)

- 핵심 개념 1~2개에 GIF. `tools/make_gifs.py` → `assets/gif/dayN-주제.gif`.
- 500KB 미만, 480px 폭, 어두운 배경, 무한 반복.

### 2-2. 외부 시각화 (선택)

- 레슨당 최대 1개: Python Tutor 또는 검증된 YouTube.

## 3. 복습 (Spaced Review)

- 레슨 **맨 위**에 `## 복습 3문제`.
- 이전 Day에서 고른 짧은 질문 3개.
- 각 질문은 `<details>`에 정답.
- Day 1은 이전 날이 없으므로 `## 워밍업 (Node로 생각해 보기)` 3문제로 대체.

## 4. 문체

- 쉬운 한국어, 존댓말, 짧은 문장. 한 문단 3문장 이하.
- **전문 용어는 처음 나올 때 괄호로 풀이**.
- "왜"를 먼저, "어떻게"는 그다음.
- 문단이 5줄 넘으면 그림·코드·목록으로 끊는다.

## 5. 코드 블록 · 인페이지 실행

| 펜스 | 용도 |
|---|---|
| ` ```python-run ` | 순수 Python. 사이트에서 Run 버튼 + 편집 + 출력 (Pyodide) |
| ` ```python ` | Django·파일 I/O 등 **로컬 실행** 코드 (읽기 전용 하이라이트) |
| ` ```javascript ` | JS 비교 |
| ` ```bash ` | 터미널 명령 (로컬) |
| ` ```mermaid ` | 다이어그램 |

규칙:

- 블록당 최대 8줄, 줄당 45자 이하.
- 트레일링 주석 금지. 결과는 `# 출력: ...` 줄로.
- `python-run`은 **표준 라이브러리만**. `django` import 금지.
- 리스트 안에 코드 블록을 들여쓰지 않는다.

## 6. 깊이를 지키는 법: `더 깊이 (면접용)`

CPython 내부, 복잡도 증명, 엣지 케이스, Django 내부는
본문에서 빼고 접기 섹션에 넣는다.

```html
<details>
<summary>🔍 더 깊이 (면접용)</summary>

마크다운 본문...

</details>
```

## 7. 연습문제 · 면접 질문

- 연습문제 **최대 3개**, 가능하면 Goals 앱과 연결.
- 문제마다 `<details>`에 **전체 정답 + 짧은 해설**.
- 면접 질문 **1~2개**, 각각 `<details>` 모범 답안.
- `<summary>` 다음·`</details>` 앞에 **빈 줄**.

## 8. 표

- 3열 이하, 셀은 짧게.
