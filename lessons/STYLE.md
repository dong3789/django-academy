# 레슨 작성 가이드 (STYLE v2)

독자: Node.js 개발자, **휴대폰으로 읽음**.
목표: 전체 과정은 면접·실무 수준, 하지만 **하루치는 10~15분에 소화**.

## 0. 분량 규칙 (가장 중요)

- 하루 = **핵심 개념 3개 내외**.
- 마크다운 **250~400줄** (접힌 "더 깊이" 포함 최대 ~450줄).
- 넘치면 내용을 버리지 말고 → `더 깊이 (면접용)` 접기 섹션으로 옮긴다.
- 그래도 넘치면 → 다음 날로 쪼갠다.

## 1. 레슨 뼈대

```text
# Day N · 제목
> 읽는 시간: 약 12분

## 오늘 배울 것
- 한 줄 1
- 한 줄 2
- 한 줄 3

## 오늘의 비유
(일상 비유 2~3문장)

## 1. 개념 A   ← 아래 "개념 5단"
## 2. 개념 B
## 3. 개념 C

## 연습문제 (최대 3개)
## 면접 질문 (1~2개)
## 오늘 정리 (3줄)
```

## 2. 개념 하나 = 5단 구성 (JS 먼저!)

익숙한 언어 → 그림 → 새 언어 순서로 배운다.

1. **JS ↔ Python 나란히 비교 (주 설명 도구)** — 같은 일을 하는
   Node 코드와 Python 코드를 **연달아** 보여준다 (폰에서는 위아래).
   - `**JS (Node)**` 라벨 + ` ```javascript ` 블록
   - `**Python**` 라벨 + ` ```python ` 블록
   - 각 블록 8줄 이하, 줄당 45자 이하. 차이점을 1~2문장으로.
2. **일상 비유** — 1~3문장.
3. **그림** — ` ```mermaid ` (사이트에서 렌더링) 또는 단순 ASCII.
   mermaid는 노드 5개 이하, `<details>` 밖에 둔다.
4. **(필요 시) 추가 Python 코드** — 함정·출력 확인용.
5. **💡 한 줄 요약** — `> 💡 ...` 형식.

### 2-1. 움직이는 그림(GIF)

- 레슨마다 **핵심 개념 1~2개**에 단계별 애니메이션 GIF를 넣는다
  (리스트 재할당, 해시 삽입, 콜 스택, MRO 탐색, yield 흐름 등).
- `tools/make_gifs.py`(Pillow)에 함수를 추가해 생성 →
  `assets/gif/dayN-주제.gif`에 저장.
- 규칙: **500KB 미만**, 480px 폭, 어두운 배경, 한글 라벨 OK,
  프레임당 0.8~1.7초, 무한 반복, 프레임 하단에 한 줄 설명.
- 마크다운: `![설명](assets/gif/day2-hash-insert.gif)`

### 2-2. 외부 시각화·영상 (선택)

- 레슨당 최대 1개: Python Tutor(pythontutor.com) 링크나
  검증된 공개 YouTube 영상. 링크는 실제로 열어 확인 후 넣는다.

## 3. 문체

- 쉬운 한국어, 존댓말, 짧은 문장. 한 문단은 3문장 이하.
- **전문 용어는 처음 나올 때 괄호로 풀이**한다.
  예: "해시(값을 숫자 지문으로 바꾸는 것)".
- "왜"를 먼저, "어떻게"는 그다음.
- 문단이 5줄 넘게 이어지면 그림·코드·목록으로 끊는다.

## 4. 깊이를 지키는 법: `더 깊이 (면접용)`

CPython 내부, 복잡도 증명, 엣지 케이스, Django 내부 동작은
본문에서 빼고 개념 끝이나 레슨 끝의 접기 섹션에 넣는다.

```html
<details>
<summary>🔍 더 깊이 (면접용)</summary>

마크다운 본문...

</details>
```

## 5. 코드 블록 규칙 (모바일)

- 블록당 최대 8줄, 줄당 45자 이하.
- 트레일링 주석 금지. 주석은 코드 위 줄에.
- 결과는 `# 출력: ...` 주석 줄로.
- 언어 태그 필수 (`python`, `javascript`, `bash`, `text`, `mermaid`).
- 리스트 안에 코드 블록을 들여쓰지 않는다.

## 6. 연습문제 · 면접 질문

- 연습문제 **최대 3개**, `### 문제 N` 소제목.
- 문제마다 `<details>` 안에 **전체 정답 코드 + 짧은 해설**.
- 면접 질문 **1~2개**, 각각 `<details>` 모범 답안
  (정의 → 원리 → 실무 함의, 5~8줄).
- `<details>` 렌더링: `<summary>` 다음과 `</details>` 앞에 **빈 줄**.
